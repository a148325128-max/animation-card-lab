# 从动画卡片到完整视频

这份教程面向第一次使用的人。目标是做出一条有声音、有画面、有字幕的完整视频，而不仅是导出一张动画卡片。

工作台处理动画镜头制作和手工拉片；写稿、录音、最终剪辑由你或其他工具完成。准备好15模板中的几个，就可以开始，不必全部用到。

## 一、先准备四样东西

- **文案**：这条视频讲给谁、希望观众看懂什么。
- **声音**：自己的口播、录音，或通过其他工具获得的配音。当前工作台不提供TTS。
- **素材**：自己的图片、产品图、截图、Logo或视频。人物/产品做环绕时，透明背景PNG通常更合适；工作台不自动抠图。
- **目标画幅**：先统一横屏或竖屏。第一次使用三种高级动画制作手机观看的视频，可先统一9:16；轮播和光流当前就是竖屏。

优先按实际声音安排时长。没有录音时可先按估时出分镜，但配音完成后需要重新对齐。

## 二、把内容拆成镜头

下面是一条45秒“介绍自己的创作流程”示例，时间仅用于安排，不是工具自动生成的结果。

| 时间 | 讲什么 | 画面 | 如何制作 |
|---|---|---|---|
| 0–6秒 | 本条主题与观众能看到的结果 | 光流标题片头 | 修改主副标题，时长6秒 |
| 6–14秒 | 使用了哪些工具或素材 | 图标环绕 | 上传自己的图标，选9:16，8秒一圈 |
| 14–23秒 | 展示三种效果或三个案例 | 三卡轮播 | 换三张自己的图，完整周期9秒 |
| 23–35秒 | 演示实际操作步骤 | 真实录屏或流程卡 | 拍摄实际操作，按声音安排节奏 |
| 35–41秒 | 说明结果与适用场景 | 对比卡或自己的作品 | 示例数字必须换成真实信息 |
| 41–45秒 | 用一句话收尾 | 金句卡或人物口播 | 保留读完与看清的时间 |

视频可以只用其中一种或两种动画，实拍、口播和录屏也能占大部分篇幅。

## 三、自己操作工作台

### 1. 安装并打开

先按[开始使用.md](../开始使用.md)准备环境。首次先导出一段短样，确认浏览器、编码和下载都可用。启动器报缺组件时，按提示处理；不要把失败的安装当作已经完成。

### 2. 选择动画并替换内容

- **基础卡片**：左侧选模板，右侧改内容、图片、颜色等。可保存到卡片库，也可导出参数。
- **环绕**：从“高级动画 · 免费”进入。选播放器或无文字图标模式；图标最多六张，每张≤1MB；中央主体图片≤4MB。播放器标题是六行复用，不代表18个单独可编辑标题。
- **轮播**：上传三张PNG/JPEG/WebP，每张≤4MB。尽量统一构图和比例；画面会按卡片区域裁切填充，上传后检查重要内容是否完整。
- **光流**：修改主副标题、颜色与时长。短标题更容易看清；可以关闭文字只做动效。

图标环绕中的AI Logo是自行上传示例。免费默认图形不同；上传自己的素材即可得到对应内容的版本。

### 3. 预览并导出

拖动时间轴，查看开头、运动中间和结束位置；核对图文、遮挡、裁切和阅读时间。确认后导出MP4，等下载链接出现。

工作台输出无声、有背景的动画片段。需要叠在口播上时，可以在剪辑软件中当作有边界的画中画；当前不能直接当透明动效覆盖。

### 4. 保存可编辑版本

建议为一条视频建文件夹，分别放“原素材、文案、配音、动画参数、动画MP4、最终视频”。基础卡片存卡库；高级动画下载JSON。JSON和MP4都保留，下次才不用从头修改。

## 四、在剪辑软件中完成整片

1. 导入口播或配音，作为安排节奏的依据。
2. 按分镜依次放入动画、录屏、实拍和其他素材；让关键画面在讲到对应内容时出现。
3. 根据声音修剪镜头长度。相差较大时返回工作台调整时长重导，不要把所有镜头任意拉快或拉慢。
4. 使用剪辑软件或其他字幕工具生成字幕，再人工核对专有名词、数字和断句。工作台本身不生成字幕。
5. 如需音乐，使用你有权使用的音轨，并让人声清楚；工作台不提供配乐。
6. 添加封面或结尾，检查字幕是否挡住重点、音画是否对齐、是否有空白或意外黑帧，再导出整片。

这些剪辑、配音、字幕操作目前由外部工具完成。工作台不能直接把一句提示词变成已配好声音的完整视频。

## 五、让 AI agent 帮你做

需要一个能在你电脑执行命令或发本机HTTP请求的agent。只能聊天、无法访问本机文件的助手，不能直接调用本地工作台。

可以把下面这段话连同解压文件夹路径交给agent：

> 请先阅读这个文件夹里的AGENTS.md、开始使用.md和AGENT_API.md，检查环境并启动工作台。根据我的已确认文案和分镜，列出可用模板，为每个动画镜头生成参数并渲染。保留原素材和参数，等待渲染任务done后核对视频时长、尺寸与文件，不重复提交仍在运行的任务。输出镜头清单、参数JSON和MP4，再告诉我哪些配音、字幕或剪辑环节尚未完成。不要把动画片段称作完整成片，也不要宣称自动恢复了参考视频代码。

agent应按顺序：

1. 用 `templates` 查看真实模板，用 `environment` 检查渲染组件。
2. 用 `defaults` 读取字段，按你的内容建立参数JSON。
3. `render 模板ID --params 参数文件 --wait`，或提交后用 `job 任务ID` 查询。
4. 核对结果后整理镜头清单。其他剪辑功能需它另有工具支持，不能默认工作台自带。

例如在包目录运行：

```sh
python3 scripts/agent-cli.py templates
python3 scripts/agent-cli.py environment
python3 scripts/agent-cli.py render gradient --params gradient.json --wait
```

参数文件例子及API返回格式见[AGENT_API.md](../AGENT_API.md)。本工具的agent渲染统一需要高级浏览器组件，即使选择的是基础卡片。

## 六、先看参考再制作：免费手工拉片

导入本地视频 → 选最多12秒 → 抽15帧 → 记录“什么元素，在什么时候，往哪里、以多大幅度变化”。例如观察卡片轮播的中心大小、上下间距、彩色/灰阶和遮挡顺序。

再判断现有模板能否表达：能就改参数；不能就记为需要新模板。当前没有在工作台内自动提取任意动效、恢复原图层或写出新代码的功能。外部agent如果能分析截图和编程，属于它的能力，不等于本工具内置能力。

## 启动与环境

基础12卡、手工拉片和全部模板预览需要Python3.10+、FFmpeg/ffprobe和现代浏览器。当前启动器面向macOS；双击“打开动画卡片实验室.command”，缺依赖会提示。详见[开始使用.md](开始使用.md)。不需要AI账号或API密钥。

新增3种高级动画的MP4导出还需要Node.js20+和Playwright浏览器组件。在包目录执行 `python3 scripts/setup-advanced.py`；脚本检查Node，将Playwright1.62.1装入本目录.runtime，优先使用现有Chrome，否则下载Chromium。需要网络，不修改全局npm环境。页面会显示导出环境是否就绪。智能体安装说明见[AGENTS.md](AGENTS.md)。

## 免费能力

- 12种基础卡片：大字强调、数据对比、三步流程、目录转章节、金句引用、勾选清单、三点时间线、条形数据、环形进度、打字机、人物名牌、三项指标。支持保存卡库，导出横/竖720p、24fps无声MP4及SVG/JSON/HTML。
- 毛玻璃环绕：播放器与无文字图标两种样式，三层轨道；支持更换六个图标和中央主体，速度、方向、玻璃、画幅调整。默认图标为自制抽象图案，可自行上传AI Logo；不分发开发者私人品牌素材库。
- 纵向卡片轮播：三张图可替换，中心放大彩色、上下缩小去色，可选文字。
- 光流片头：光流→圆环→四角星→渐变标题卡，支持主副标题、颜色、文字开关和时长。
- 高级动画保存/读取参数JSON，可导出30fps无声MP4；环绕支持三画幅，轮播及光流当前为720×1280竖屏。高级模板参数不写入基础卡片库，请用各自的保存参数入口。
- 免费手工拉片：导入≤250MB本地视频，选取≤12秒片段，抽取15帧、记录观察与查看选段，手工选择结构。它不自动识别图层、恢复代码或生成任意动画。

## 当前边界

自动AI分析/仿写、音频自动配时、透明视频和付费流程尚未接入。付费功能还在定义中，不影响以上免费能力。仅在同一台Mac做清洁解压和真实导出验证，尚无其他设备或Windows/Linux验收。

导入素材、卡库和导出作品保存在本地data/；runtime只用于本机导出。不要把自己的整个使用目录上传GitHub。参考视频、截图、音频、私人卡库和运行缓存均未包含在免费包中。

## AI agent调用

支持本机HTTP/CLI：列出15模板、读取默认参数、传参数渲染、查询任务，以及上传视频和抽帧。详见[AGENT_API.md](AGENT_API.md)。无需专属agent插件；命令行批量渲染依赖高级浏览器组件。当前不是远程MCP服务，也不内置自动理解任意参考动画。

## 安装与使用

需要 Python 3.10+、FFmpeg（含 ffprobe）和浏览器。当前启动入口面向 macOS；依赖需另行安装，不需要 Node、Playwright、Codex、Claude 或 API 密钥。

阅读 [开始使用.md](开始使用.md)，然后双击 `打开动画卡片实验室.command`。启动器检查环境，缺失时提示原因；不会自动安装依赖。若使用智能体协助安装，请让它先读使用说明、许可和启动脚本，再运行环境检查；安装依赖无需修改本项目源码。

## 当前能力

- 4 种卡片：大字强调、数据对比、三步流程、目录转章节。
- 修改内容和 Logo，保存卡片库；导出横/竖 720p、24fps、无声 MP4，以及 SVG、JSON、独立 HTML。
- 导入本地视频，选取最多 12 秒片段，抽取 15 帧并记录观察；重建结构由使用者手工选择。

自动 AI 分析/仿写、音频自动配时、透明视频和付费功能尚未接入。已完成同一台 Mac 的清洁解压验证，尚未完成其他电脑或 Windows/Linux 验证。
